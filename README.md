# PDF-Slimmer 2.0

כלי מקומי ב-Python להמרת קובצי PDF ולהקטנתם, עם ממשק עברי.

## ברירת מחדל מומלצת לספרים סרוקים
ברירת המחדל בממשק היא כעת **שחור־לבן — דחיסה חזקה** ב־200 DPI, ללא חידוש OCR. זה בדרך כלל חוסך הרבה יותר מקום מקובצי סריקה צבעוניים, אך מסיר טקסט OCR, קישורים וצבעים. למי שצריך OCR, בחר במפורש במצב החכם (שעלול לחסוך פחות) או התקן OCRmyPDF להפעלה מחדש של OCR. אם הקובץ המומר גדול יותר, התוכנה תשאיר עותק של המקור במקום הפלט, ותדווח על כך.

## יכולות
- **חכם**: שומר על מסמכים דיגיטליים ועל PDF בעל OCR באמצעות אופטימיזציית PDF ללא השטחה. מסמכים סרוקים ללא OCR מומרים לשחור־לבן.
- **ללא אובדן**: מיטוב מבנה PDF ללא שינוי תמונות.
- **גווני אפור**: המרה באמצעות Ghostscript (דורש התקנה נפרדת).
- **שחור־לבן / ניקוי רקע**: רינדור עמודים ב-DPI נבחר, דחיסת CCITT Group 4, עיבוד מקבילי וחיסכון בזיכרון.
- ביטול עבודה בין עמודים, אי-דריסת מקור, וחזרה למקור אם הפלט גדול יותר.
- אפשרות להריץ OCR מחדש בעזרת OCRmyPDF (נדרש התקנה נפרדת); אם אין OCR במקור המערכת אינה יוצרת OCR אוטומטית.

## הפעלה
```powershell
git clone https://github.com/avtsye/PDF-Slimmer.git
cd PDF-Slimmer
python -m pip install -r requirements.txt
python app.py
```

או לחץ על `start-windows.bat`.

## CLI
```powershell
python cli.py book.pdf --mode smart --workers 2
python cli.py book.pdf --mode bw-clean --dpi 200 --no-ocr
```

## JBIG2 לא מקוון
- קוד התמיכה נמצא ב-`jbig2_backend.py`. התוכנה אינה פונה לרשת בזמן ההמרה.
- יש לספק את המקודד הבינארי `jbig2enc` (פקודת `jbig2`) כ-`bin/jbig2.exe` ב-Windows, או שיהיה זמין ב-PATH.
- כדי לכלול אותו בתוך EXE יחיד, יש להוסיף `bin/jbig2.exe` למאגר *לפני* ריצת Build Windows EXE; התהליך יארוז אותו אוטומטית. רצוי לוודא את רישיון ואמינות הקובץ לפני העלאה.
- ללא קובץ המקודד, מצב JBIG2 **אינו זמין**. ה-EXE הרגיל עדיין יכול להיבנות, אך לא יבצע דחיסת JBIG2.
- מצב JBIG2 משתמש בדחיסה גנרית ללא איבוד ביטים, ללא `-s` או clustering. המרה מקובץ צבעוני לביט אחד עדיין מאבדת מידע.
- מצב JBIG2 אינו משמר קישורים וסימניות. חידוש OCR זקוק ל-OCRmyPDF מקומי.
- זהו מסלול ראשוני שדורש בדיקת תאימות לפלט בפועל ב-Windows עם מקודד מותקן, לפני הסתמכות עליו לספרים חשובים.

## תלות אופציונלית
- Ghostscript: דרוש למצב גווני אפור (אינו כלול ב-EXE).
- OCRmyPDF + Tesseract + קבצי שפה: דרושים לחידוש OCR בעת הפיכת PDF עם OCR לתמונות. התקן בנפרד. מצב חכם אינו דורש אותם.
- JBIG2: קוד התמיכה משולב, אך נדרש לספק מקודד בינארי בנפרד. 

## אזהרות
- המרת סריקות לשחור־לבן היא **אובדנית**: ייתכן אובדן צבע ופרטים חלשים.
- המצבים המרונדרים יכולים לאבד סימניות, קישורים, טפסים וטקסט; ה-OCR המחודש תלוי בתוכנה חיצונית.
- אם האפשרות `keep_smaller` מופעלת והפלט גדול מהמקור, נשמר עותק המקור **שאולי עדיין צבעוני**.
- הקבצים נשמרים מקומית בלבד. מומלץ להשוות מספר דפים לפני עיבוד ספר גדול.

## בדיקות ובנייה

```powershell
python -m pip install pytest

```
