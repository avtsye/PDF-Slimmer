# PDF-Slimmer

כלי מקומי ל-Windows להקטנת קובצי PDF והמרת סריקות צבעוניות לגווני אפור או שחור־לבן.

## אפשרויות
- **גווני אפור** (Ghostscript): המרת PDF ללא הפיכת כל עמוד לתמונה; לרוב שומר טקסט ניתן לחיפוש, אך יש לבדוק את הפלט.
- **שחור־לבן**: רינדור כל עמוד לתמונה של ביט אחד ושמירה באמצעות CCITT Group 4 (Pillow PDF).
- **שחור־לבן + ניקוי רקע**: ניגודיות וניקוי רעש לפני הסף. עלול למחוק אותיות חלשות — חשוב לבדוק חזותית.
- עיבוד אצווה, בחירת DPI, הצגת חיסכון, מניעת דריסת מקור ושמירה אוטומטית של המקור אם ההמרה גדולה יותר.

## הפעלה ב-Windows
1. התקן Python 3.12 ומעלה (כולל Tkinter).
2. הורד את המאגר כ-ZIP וחלץ; לחץ `start-windows.bat`.
3. אפשר להוריד קובץ EXE מה-Artifacts של GitHub Actions לאחר ריצת **Build Windows EXE**.
4. **למצב גווני אפור בלבד:** התקן Ghostscript והוסף את `gswin64c.exe` ל-PATH. ה-EXE אינו כולל Ghostscript.

## פקודת שורת פקודה
```bash
python cli.py my-book.pdf --mode bw --dpi 200 --output converted
python cli.py my-book.pdf --mode gray --output converted
```

## הבדלים ואזהרות
- מצבי שחור־לבן משטחים עמודים: הם **מסירים שכבת טקסט OCR, קישורים, טפסים וסימניות PDF**. המקור נשאר ללא שינוי.
- המרה לא תמיד מקטינה קובץ. אם האפשרות 'שמור את המקור כשקטן יותר' מופעלת, נכתב עותק של המקור במקום הגרסה המומרת, ולכן הפלט עשוי **לא להיות שחור־לבן**.
- PDF קיים עם תמונות JPEG צבעוניות דחוסות מאוד עלול לגדול אחרי שחור־לבן.
- במקרים של תרשימים בצבע או סימון צבעוני, מידע חזותי עלול להיעלם.
- **אין עדיין JBIG2 או שימור OCR אחרי המרה לשחור־לבן.**
- רזולוציה ניתנת לבחירה בין 100–400 DPI; ברירת מחדל 200.
- אין העלאה לענן; הקבצים נשארים על המחשב.
